ME'RAJ INTERNATIONAL SCHOOL - WEBSITE SETUP

1. Create a MySQL database on your hosting.
2. Import database.sql into the database.
3. Open config.php and replace DB_NAME, DB_USER and DB_PASS with your database details.
4. Upload the whole website to PHP hosting such as Hostinger. GitHub Pages does not run PHP/MySQL.
5. Open setup_admin.php once and create the school administrator account.
6. Immediately delete setup_admin.php from the server after creating the admin account.
7. Log in through /admin/login.php.
8. Use Admin > Media to upload Gallery photos, Videos and Audios. No programming is required for future uploads.
