ME'RAJ INTERNATIONAL SCHOOL MAIDUGURI WEBSITE

This version follows the Darul-Furqan sample layout idea but is kept for Me'Raj International School only.

Preserved original school assets:
- assets/images/school-logo.png
- assets/images/students.jpg

Main files:
- index.php
- assets/css/style.css
- assets/js/app.js
- admin/ (login, dashboard, gallery/video upload)
- gallery.php
- videos.php
- config.php
- database.sql

Admin workflow:
1. Create the MySQL database using database.sql.
2. Edit DB_USER and DB_PASS in config.php.
3. Open setup_admin.php once and create the admin account.
4. Delete setup_admin.php from the server.
5. Open /admin/login.php.
6. Use Media Manager to upload Gallery Photos or Videos.
7. Uploaded media appears automatically on the website; no HTML/CSS/JS editing is needed.

Only Gallery and Video media are included. No Audio Library, application system or unrelated sections are included in this version.
